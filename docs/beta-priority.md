# Beta Status and Priority Tracker

## Completed in current beta

- Whiteboard canvas with modern `tldraw` UX
- Intentional in-canvas shape snapping (hold `Shift` while drawing)
- Shape snapping targets: rectangle, circle, arrow
- Raw handwriting preserved when `Shift` is not pressed
- Session title + timer strip
- Timer persistence across refresh (including resume delta)
- Session snapshot export/import (title + timer state)
- CLI workflow: `pnpm session:stop`

## Priority order to reach 100% beta

1. **Free-draw UX polish** (tablet/pen-first comfort, fast mode switching)
2. **Snapping reliability tuning** (rectangle/circle/arrow confidence calibration)
3. **Session quality-of-life** (faster clear/reset and export flow)
4. **Keyboard shortcut discoverability** (visible in-app hinting)
5. **Mobile/small-screen behavior** for quick annotations

## Current focus

- Final stabilization for free-draw teaching sessions.
